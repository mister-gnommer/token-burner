# Favorite reply context v1
Supplement to extract-evidence-v3: a bare list responding directly to a verified question asking for the reply author's personal favorites can establish positive preference for the listed names. Store the exact favorite question as separately attributed context, and keep the verbatim reply list as preference_quote. This exception does not apply to recommendations, genre suitability, third-party favorites, or unknown reply linkage. Context never transfers the parent's own preferences to the respondent. Do not assume an unverified alias is resolved by this context.
